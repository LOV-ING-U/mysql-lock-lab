## 측정 범위와 한계

- 임베딩·검색·생성 시간은 Kotlin 서비스가 측정한 각 HTTP 호출의 전체 시간이다. 요청 직렬화, 네트워크, 상위 서비스 처리와 응답 파싱을 포함한다.
- OpenAI 시간에는 네트워크·제공자 대기·답변 생성이 섞여 있으며, 모델 내부 추론 시간만은 분리하지 못한다.
- 내부 기타 시간은 RAG 서비스 전체 시간에서 세 HTTP 구간을 뺀 값이다.
- 계측 구간 밖 시간은 클라이언트 전체 시간에서 RAG 서비스 시간을 뺀 값이다. 컨트롤러 처리, 최종 JSON 직렬화, 로컬 전송 및 클라이언트 응답 처리 등을 포함한다.
- 구성요소의 합과 서비스 전체 시간의 오차는 응답 헤더 반올림으로 최대 0.001ms였다.
- 단계별 중앙값을 합한 값은 전체 중앙값과 같을 필요가 없다.
- 첫 요청의 전체 시간은 5.475초로 가장 길었다. 연결 초기화 등 원인은 이번 실행에서 따로 분리하지 않았다.
- 이전 실행보다 응답 시간이 달라진 것은 최적화 성과가 아니다. 생성 모델 응답·네트워크 상태 등이 달라지는 단일 순차 실행이며, 동시 부하 성능이나 SLA로 일반화할 수 없다.
